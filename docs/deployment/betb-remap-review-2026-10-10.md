Spell CDB rows store ATK/DEF as 0/0; the API omits these fields. A Link CDB stores its arrow mask in DEF: both old and current rows have 135, with Link rating 4. The API has no DEF, Link rating 4, and arrows Bottom-Left, Bottom, Bottom-Right and Top; these decode to mask 135. All monster API ATK/DEF values agree with the CDB. All monster levels, attributes and races also agree. Effect differences above explain why an exact text rule must not infer these nine mappings. These are reviewed identity exceptions, not changes to the engine text.

The final mapping has 82 entries: 71 main-card automatic matches, two historical artwork mappings, and nine reviewed overrides. There are no unresolved playable identities. The 80 old main cards all resolve to official rows; old alternate artworks `101402136` and `101402144` resolve to their official main rows. BETB EN097–EN100 already had official passcodes and need no temporary-code remap. Retained EN081–EN096 keep their current preview codes.

The old preview also has two non-playable Token rows: `101402149` (Glimmer Token) and `101402154` (Scapegoat Token). The automatic and override policies exclude Tokens. They have no remap. Current release Token rows are `41458362` and `3129528`. These two old codes remain unsupported if used in a saved deck. No uncertain playable mapping was added.

Required saved-deck mappings are `101402003 → 40275470` (Jinzo - Energy Shocker), `101402036 → 17242022` (Red-Eyes Black Dragon Exceed), `101402052 → 40235813` (Dark Time Wizard), `101402054 → 3129527` (Sleepy Scapegoats), and `101402070 → 65118318` (Foolish Graverobber).
